# Zoo Kids

Base de catálogo para a Zoo Kids, criada com React, TypeScript e Vite.

## Executar

Requer Node.js 20.19+ ou 22.12+.

```bash
npm ci
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

## Fotos

Coloque as imagens na pasta `public/fotos` usando os nomes indicados em
[`public/fotos/ADICIONE-AS-FOTOS-AQUI.txt`](public/fotos/ADICIONE-AS-FOTOS-AQUI.txt).
As imagens enviadas pelo chat não foram disponibilizadas como arquivos no ambiente.
Até adicioná-las, o site mostra espaços reservados.

Os nomes dos produtos são demonstrativos. Preços, tamanhos e canal de contato
ainda precisam ser informados pela Zoo Kids.
